**「輸出管理の複雑性は5年で3倍に増加。しかし対応する企業の体制は変わっていない。」**

### トーク
「地政学リスクが高まるなかで、米国BISのEntity List掲載数は2019年の約200社から2024年には600社超に膨れ上がっています。日本企業も無関係ではありません。経産省の外為法に関する行政指導件数も年々増加しており、制裁は『米国の話』ではなく『日本企業の経営リスク』になっています。しかし、こうした規制の複雑化に対応できている企業は少数です。」

## SLIDE 05 — As-Is: 現在の輸出管理体制（LIGHT）
### キーメッセージ
**「典型的な現状: 人 → Excel → 外部委託 → 承認。このフローに潜むリスク。」**

### 現状フロー図
```
新規取引発生
  → [担当者] 手動でECCN/HSコード調べる（2〜5日）
  → [Excel] 該非判定シートに記録（バージョン管理なし）
  → [外部専門家] 委託（2〜8週間・50〜200万円）
  → [上長] 承認（内容理解不十分でもハンコ）
  → [出荷] ← ここで問題があっても気づかない
```

### 潜在リスクの可視化
| ステップ | リスク | 深刻度 |
|---------|--------|--------|
| 手動調査 | ECCN誤認・抜け漏れ | ★★★ |
| Excel管理 | 変更追跡不能・監査証跡なし | ★★★ |
| 外部委託 | 速度・コスト・知識が社内に残らない | ★★ |
| 承認フロー | 形骸化・実効性なし | ★★ |
| キャッチオール判断 | 専門知識なしで自己判断 | ★★★ |

### トーク
「多くの企業が今まさにこのフローで運用されています。問題は、このフローが『機能している』ように見えて、実は大きなリスクを内包している点です。Excelのバージョン管理がない、外部委託先の知見が社内に残らない、キャッチオール規制の判断は担当者の経験値に依存している。どれも個別には『何とかなっている』ように見えても、一度問題が起きると取り返しがつかない。」

## SLIDE 06 — 3つの根本課題（MEDIUM DARK）
### キーメッセージ
**「属人化・コスト・規制カバレッジ——この3つは連鎖している。」**

### 課題1: 専門知識の属人化
- 外為法＋ECCN＋HS コードを体系的に理解できる人材は国内で極めて希少
- 担当者の退職・異動 = 組織の輸出管理機能が一夜にして消滅
- 後任育成には平均2〜3年

### 課題2: 外部委託の限界
- 単発委託: 50万〜200万円/件、2〜8週間
- 年間100件の取引を全件委託: **2〜5億円/年**
- しかし速度が求められる案件では「間に合わない」

### 課題3: キャッチオール規制の盲点
- リスト規制外の汎用品でも**輸出令第4条・第4条の2**が適用
- 「用途・仕向地・取引パターン」の複合判断が必要
- 専門家でなければ自己判断が困難 → 見落とし率高

### トーク
「この3つの課題は互いに連鎖しています。人材が育たないから外部委託に頼る。外部委託はコストがかかるから判断件数を絞る。絞るからキャッチオールの見落としが起きる。この悪循環から抜け出す方法は、根本からアーキテクチャを変えることです。」

## 付録A — よくある質問（想定反論）

**Q: 既存のERPやシステムと統合できますか？**
A: API対応でほぼすべての既存システムと連携可能です。Phase 3での本格統合前に、CSV入力での運用も可能です。

**Q: 判定の法的責任は誰が持つのですか？**
