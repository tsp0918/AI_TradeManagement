02 Case Study
Case Study — 制裁実例
制裁金の発動（AMATの事例）
Applied Materials、半導体製造装置の対中輸出で DOJ 調査——$153M 超の制裁合意は「他人事」ではない
02 / 08
概要
Applied Materials（AMAT）
米国最大の半導体製造装置メーカー。DOJ（米国司法省）が EAR（輸出管理規則）違反の疑いで捜査。中国半導体メーカー SMIC（エンティティリスト掲載）への装置出荷が焦点。
$153M+ 報道ベースの制裁
合意報告額
刑事 法人・個人への
刑事罰リスク
事件の経緯
2020–21
SMIC が米商務省のエンティティリストに掲載。AMAT は第三国経由の出荷を継続との疑惑。
2022–23
DOJ・Commerce Dept による調査開始。株主訴訟も並行。株価への影響と経営陣の対応が注目される。
2024
$153M 超の民事和解合意が報道。輸出コンプライアンス体制の全面見直しを実施。
⚖
刑事罰
個人への懲役刑・法人への重大罰金。代表者の監督責任も問われる。
🚫
行政処分
輸出業務停止命令。グローバルサプライチェーンの即時停止リスク。
📉
信頼失墜
株価下落・顧客離反・資金調達コスト上昇。ブランド価値の毀損。

03 Constraint
Constraint — AI 活用の壁
安全保障貿易管理における AI 活用の難易度
「汎用 LLM に任せる」では解決できない——コンプライアンス AI 固有の 3 つの壁と、NeuroSymbolic AI による突破口
03 / 08
🤔
壁 1
ハルシネーション
存在しない条文番号を引用。数値閾値の判定で一貫性を欠く。コンプライアンス文脈での「もっともらしい誤り」は最悪のパターン。
📅
壁 2
知識カットオフ問題
外為法・輸出令は頻繁に改正される。トレーニング後の改正内容を LLM は知らない。「古い法律ベースで OK」は法的リスクそのもの。
⬛
壁 3
判断根拠の不透明性
「規制対象ではありません」と言われても根拠が示せない。担当者がダブルチェックできず、監査証跡にもならない。
✦
解法 1
規制知識 = オントロジー
LLM に規制を「覚えさせない」。正確性はオントロジー JSON が保証。法改正 = シード更新のみ。
✦
解法 2
Neural × Symbolic 分業
FAISS/LLM は候補抽出・対話生成担当。閾値判定・条文適用は Symbolic ルールエンジン担当。
✦
解法 3
三層の根拠付き出力
条文・スコア・一致語・判定ロジックをすべて記録。PDF レポート + DB 監査ログで説明責任を担保。

Symbolic キャッチオールエンジン
